# UI Direction — Creator Tracker

## Core Philosophy

Creator Tracker is not a generic productivity dashboard.

It is a premium creator operating system designed for focused creators, editors, freelancers, and digital builders.

The UI must feel:

* calm
* intentional
* cinematic
* structured
* quietly premium
* emotionally focused

The interface should create the feeling of:

* entering a focused creative workspace
* operating inside a refined professional tool
* using software built for deep work

The app should feel expensive through:

* restraint
* hierarchy
* interaction quality
* typography discipline
* spacing precision
* surface layering
* visual confidence

NOT through:

* loud effects
* flashy gradients
* oversized animations
* aggressive glassmorphism
* oversaturated accents

---

# Premium Feel Philosophy

A premium interface is not created through decoration.

A premium interface is created through:

* clarity
* consistency
* controlled motion
* confident spacing
* intentional hierarchy
* predictable interactions

Every interaction should feel:

* smooth
* stable
* lightweight
* responsive
* emotionally calm

The user should never feel:

* visual chaos
* cheapness
* clutter
* uncertainty
* interaction confusion

The app should feel:

* reliable
* refined
* mature
* production-ready

---

# UI Personality

Creator Tracker should feel like a hybrid between:

* Linear
* Notion
* Spotify desktop
* Apple system interfaces
* professional creative software

The interface should prioritize:

* structure over decoration
* hierarchy over color
* calmness over excitement
* readability over visual tricks
* usability over experimentation

---

# Visual Hierarchy Rules

## Hierarchy Must Be Structural

Hierarchy should primarily come from:

* spacing
* typography scale
* alignment
* contrast separation
* surface elevation

NOT from:

* bright colors
* glowing borders
* aggressive highlights
* oversized cards

---

## Information Density

The UI should feel:

* dense enough to feel professional
* spacious enough to breathe

Avoid:

* giant empty dashboard sections
* cramped enterprise layouts
* oversized cards
* excessive whitespace

---

## Focus Direction

The UI should naturally guide the eye through:

1. typography
2. spacing
3. surface depth
4. controlled contrast

The user should instantly understand:

* where they are
* what is active
* what is interactive
* what is secondary

without needing strong visual effects.

---

# Surface Layering System

Creator Tracker relies heavily on surface hierarchy.

Every layer must feel intentional.

---

## Layer Philosophy

### Base Layer

The app background.
Should feel stable and atmospheric.

### Secondary Layer

Sidebars and structural panels.
Should feel attached to the workspace.

### Surface Layer

Cards, sections, logs, widgets.
Should feel clearly separated from the base.

### Elevated Layer

Dropdowns, popovers, modals.
Must feel floating and premium.

---

## Surface Separation

Surfaces should NEVER visually merge together.

Especially in light theme:

* cards
* dropdowns
* sidebars
* modals
  must feel visually separated.

Separation should come from:

* subtle contrast
* soft borders
* controlled shadows
* elevation hierarchy

NOT heavy effects.

---

# Hover State Philosophy

Hover states represent attention, not selection.

Hover should feel:

* subtle
* lightweight
* premium
* calm

Hover may use:

* slight surface tint shift
* slight border emphasis
* slight brightness lift

Hover should NOT:

* display selection indicators
* aggressively glow
* drastically change scale
* visually overpower the layout

---

# Selected / Active State Philosophy

Selected states represent system truth.

Selected state must feel:

* stronger than hover
* structurally grounded
* visually confident

Allowed:

* active indicator dot
* stronger contrast
* stronger surface separation
* clearer hierarchy

The active indicator dot:

* represents active state ONLY
* must NEVER appear on hover state

Hover and selected states must remain visually distinct.

---

# Interaction Quality Standards

The interface should feel:

* frictionless
* responsive
* intentional

Interactions should feel:

* precise
* stable
* smooth
* lightweight

---

## Motion Rules

Animations must:

* support clarity
* never distract
* never delay workflows

Preferred durations:

* 150ms–200ms

Avoid:

* bouncy animations
* overscaled transitions
* spring-heavy motion
* exaggerated fades

---

## Layout Stability

Interactive states must NEVER:

* shift layout
* resize containers
* move surrounding elements
* create visual jumping

The UI should feel structurally locked and stable.

---

# Typography Direction

Typography is one of the most important premium signals.

The app should feel:

* clean
* sharp
* readable
* controlled

---

## Typography Rules

Use:

* restrained font scales
* consistent spacing
* predictable weights

Preferred weights:

* 400
* 500
* 600

Avoid:

* ultra-heavy weights
* giant display text
* decorative typography

---

## Readability Rules

Muted text must remain readable.

Secondary information should feel:

* softer
* quieter
* lower hierarchy

But NEVER:

* invisible
* washed out
* inaccessible

Especially in light theme.

---

# Border & Shadow Philosophy

## Borders

Borders define structure.

Preferred borders:

* 1px
* subtle opacity
* theme-aware
* low-noise

Borders should help:

* separate surfaces
* define hierarchy
* stabilize layouts

---

## Shadows

Shadows are used sparingly.

Shadows are reserved mainly for:

* dropdowns
* modals
* elevated overlays
* floating panels

Avoid:

* giant blurry shadows
* floating-card overload
* fake depth everywhere

---

# Spacing & Radius Philosophy

The UI should feel:

* mathematically aligned
* disciplined
* calm

---

## Radius Rules

Use:

* small-to-medium radii
* subtle curvature
* professional shapes

Avoid:

* bubble UI
* excessive rounding
* playful oversized corners

---

## Spacing Rules

Follow a consistent spacing grid.

Preferred spacing rhythm:

* 4px
* 8px
* 12px
* 16px
* 24px
* 32px

Spacing consistency is critical for premium feel.

---

# Dropdown & Popover Standards

Dropdowns and popovers are critical premium-feel components.

They must feel:

* elevated
* isolated
* intentional
* lightweight

---

## Dropdown Rules

Dropdowns should:

* float clearly above the canvas
* maintain clean hierarchy
* use readable contrast
* preserve theme consistency

Especially in light theme:

* avoid flat gray sheets
* avoid dark-theme leakage
* avoid muddy borders

Dropdowns should feel:

* refined
* clean
* softly elevated

NOT:

* default browser menus
* cheap Tailwind popovers

---

# Sidebar Interaction Standards

The sidebar is the navigation spine of the app.

It should feel:

* calm
* stable
* precise
* lightweight

---

## Sidebar Hover Rules

Hover:

* subtle surface feedback
* no active indicators
* no visual noise

---

## Sidebar Selected Rules

Selected items:

* stronger hierarchy
* subtle active depth
* clear active indicator

Selected state should feel:

* grounded
* intentional
* persistent

---

# White Theme Rules

The Cinematic Light theme requires stronger hierarchy discipline.

White theme exposes weak UI structure immediately.

---

## White Theme Priorities

White theme must maintain:

* readable muted text
* visible borders
* clear surface separation
* dropdown depth
* hover clarity
* selected clarity

Avoid:

* invisible text
* washed surfaces
* flat gray layouts
* weak hierarchy

---

# Dark Theme Rules

The dark theme is the flagship cinematic experience.

It should feel:

* atmospheric
* immersive
* focused
* low-fatigue

Dark theme depth should come from:

* layered darkness
* controlled contrast
* subtle glow
* restrained highlights

NOT loud neon effects.

---

# Ambient Glow Rules

The app includes a fullscreen cursor-follow ambient glow system.

This glow should feel:

* atmospheric
* cinematic
* soft
* integrated

In light theme:

* reduce intensity
* soften opacity
* avoid strong blue glow

The glow should support atmosphere, not dominate the UI.

---

# What To Avoid

Never allow Creator Tracker to become:

* generic enterprise SaaS
* template-looking dashboard
* flashy Dribbble concept
* over-animated interface
* glow-heavy cyberpunk UI
* loud glassmorphism experiment

Avoid:

* default Tailwind blue states
* excessive blur
* giant shadows
* inconsistent spacing
* mixed border systems
* random accent colors

---

# Final Product Feeling

Creator Tracker should feel like:

* a serious creator workspace
* a refined operating system
* a stable professional tool
* software built for focus and consistency

The UI should communicate:

* trust
* structure
* focus
* control
* quiet confidence

The app should look premium.

But more importantly:

The app should FEEL premium during real interaction.
